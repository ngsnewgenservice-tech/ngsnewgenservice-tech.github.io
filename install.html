Install PolySubs

Beta version 4.0.2 · Chrome and Microsoft Edge on computers

PolySubs will soon be available in the Chrome Web Store and Microsoft Edge Add-ons. Until then, you can install the beta version in less than a minute:

⬇ Download PolySubs 4.0.2

Steps

  1. Download the file above and unzip it (right-click → Extract all).
  2. Open chrome://extensions in Chrome, or edge://extensions in Microsoft Edge.
  3. Turn on Developer mode.
  4. Click Load unpacked and select the unzipped PolySubs folder.
  5. Open any YouTube video that has subtitles. Click the PolySubs icon to choose your languages.

Premium

Open the extension, go to the ⭐ Pro tab and click Get Premium. After payment, paste your license key in the same tab and click Activate.
